# AI Chatterbox

AI Chatterbox is a real-time chat application with AI-powered chat functionality.

## Features

- User Signup & Login
- JWT Authentication
- Real-time Messaging
- AI Chat
- MongoDB Database
- REST APIs
- Socket.IO

## Tech Stack

Node.js, Express.js, MongoDB, Socket.IO, JWT, OpenAI API, HTML, CSS, JavaScript
